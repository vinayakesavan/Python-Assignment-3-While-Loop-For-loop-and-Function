                    Python Assignment 3: While Loop, For loop and Function
1.Overview
This assignment focuses on Python concepts including while loops,
for loops, control statements (else, break, continue, and pass), and user-defined functions.

2. Objectives
•	Practising while loop to repeat a block of code.
•	Use of break and continue.
•	Use of else clause with while loop.
•	Creating a multiplication table using for loop and range.
•	Generate a function to calculate body mass index.

3.Topics Covered
While loop and control statements: Number guessing game
•	Generated a random number between 1 and 10 by using random and randint function.
•	Used while loop to allow guessing up to 3 attempts.
•	Provided feedbacks for each of the guess.
•	Used a continue when the user guess is in the range 1 to 10.
•	Used a break when the user guesses.
•	Used else with while loop to allow the user to keep guessing until they get the correct number or run out of attempts.

For loop: Multiplication table generator
•	 Prompted the user for Input. 
•	 Use a for loop to iterate through the numbers 1 to 10.
•	 Calculated the product of the user's number and the current number from the loop. 
•	 Displayed the multiplication table in the format "number x i = result".

  Function: BMI calculator
•	Created a function named calculate_bmi (weight, height) that returns the BMI.
•	Prompted the user for their weight (in kg) and height (in meters). 
•	 Used the function to calculate and display the BMI.
